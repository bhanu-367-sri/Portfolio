# Bhanu Sri Damisetty — Developer & AI Portfolio

> A modern, performant, and scalable portfolio website built with clean vanilla web technologies, dynamic data architecture, dark/light theme switcher, and instant search & filtering.

![Portfolio Preview Banner](my-photo.jpg)

---

## 🌟 Highlights & Features

- **⚡ Zero-Dependency & Lightning Fast:** Pure HTML5, CSS3 Custom Properties, and ES6+ JavaScript. No bulky frameworks, build tools, or `node_modules` required.
- **📁 Data-Driven Architecture:** All data (Projects, Certificates, Skills, Bio, Links) is maintained in `js/data.js`. Updating your portfolio takes seconds without touching HTML markup.
- **🎨 Dark & Light Mode Support:** Smooth theme toggling with automatic system preference detection and `localStorage` state persistence.
- **🔍 Real-Time Project Search & Filtering:** Filter projects by domain (*AI & Machine Learning*, *Web & Full Stack*, *Tools*) or search across project titles, tags, and descriptions instantly.
- **📜 Verified Certificates & Credentials Gallery:** Dedicated showcase for course certifications, hackathons, and standardized assessments with direct credential verification links.
- **🔍 Interactive Project Architecture Modals:** Click on any project to inspect the full case study, system architecture highlights, technologies applied, and source code.
- **📄 In-Browser Resume Preview & Download:** Built-in modal resume summary plus direct 1-click download support for `resume.pdf`.
- **🛠️ Visual Update Companion (`update-helper.html`):** Built-in GUI tool to generate copy-pasteable JavaScript code blocks for new projects and certificates.
- **📱 Fully Responsive & Accessible:** Optimized for all screen sizes from mobile to 4K, keyboard accessible, with smooth scroll navigation and reading progress indicator.

## 🚀 Quick Start

### 1. View Locally
Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Safari).

### 2. Deploy to GitHub Pages (Free Hosting)
1. Push this folder to a GitHub repository (e.g. `bhanu-367-sri.github.io`).
2. Go to **Settings** → **Pages** → Source: **Deploy from a branch** (`main` / `root`).
3. Your portfolio will be live at `https://bhanu-367-sri.github.io/`!
